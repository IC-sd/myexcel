## 1. 项目定位

本项目是面向 GitHub 的通用类 Excel 应用构建平台，不是某家公司的 ERP、OA、排产或打印项目。产品保持两个使用视角：

- **设计模式**：配置表格模板、字段绑定、基础关系和发布版本。
- **运行模式**：在已发布模板中填写、保存、查询和重新打开记录。

阶段 1 只证明“表格模板可以成为结构化数据应用”；企业权限、审批中心、审计运维和复杂集成不是 MVP 完成条件。

## 5. 验证摘要与明确限制

2026-09-24 完整复验：77 项测试中 66 项通过、11 项可选 MySQL 专项因本轮未配置而跳过；生产构建通过，合成 100/1,000/10,000 行性能预算通过。Ubuntu、macOS 公开 CI `35946977206` 均完成干净安装、测试、构建和启动探针；Windows 本地完成构建与全新数据目录浏览器流程，合成记录的打开、提交、通过、刷新后持久化和状态筛选通过。

依赖审查发现 Univer 间接锁定旧 `nanoid`，已定向覆盖到修复版 5.1.16；开发依赖 Vite 升到 7.3.5。生产依赖审计已清零；完整审计尚有一个仅涉及独立 esbuild 开发服务器的低危告警（沿 Vite 依赖链展示 3 项）。本项目不运行 esbuild 独立服务，开发服务器仅绑定 `127.0.0.1`。修复提交已通过公开 CI `35961613762` 的 Ubuntu/macOS 干净安装、测试、构建与启动探针。

明确限制：

- 只承诺 `.xlsx` 基础导入与兼容提示，不承诺旧 `.xls` 或全部 Excel 高级特性；
- 不承诺多人实时协作、复杂 BPMN、企业组织权限或真实业务现场适配；
- Univer 工作区包体仍较大；
- 本地 JSON 记录与 SQLite 元数据不是统一事务；MySQL 适配器同样不与 SQLite 元数据组成跨库事务。

## 8. 阶段 4：键盘可达性增强

已完成一个独立增强项：登录与工作台外壳的键盘焦点可见；工作台首个 Tab 提供“跳转到主要内容”，Enter 将焦点移到当前主区域，再按 Tab 进入页面操作。视图与工作簿标记当前状态；隐藏文件控件退出 Tab 顺序；状态和登录错误提供辅助技术提示。不增加依赖，也不改变模板、记录和接口，撤销本批界面改动即可移除增强。
