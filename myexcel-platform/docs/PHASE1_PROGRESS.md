## 1. 项目定位

本项目是面向 GitHub 的通用类 Excel 应用构建平台，不是某家公司的 ERP、OA、排产或打印项目。产品保持两个使用视角：

- **设计模式**：配置表格模板、字段绑定、基础关系和发布版本。
- **运行模式**：在已发布模板中填写、保存、查询和重新打开记录。

阶段 1 只证明“表格模板可以成为结构化数据应用”；企业权限、审批中心、审计运维和复杂集成不是 MVP 完成条件。

## 5. 验证摘要与明确限制

最近一次完整基线验证为：非 MySQL 基础测试 56 项通过、11 项按预期跳过；隔离 MySQL 全量 67 项通过；Vite 生产构建通过；宽屏、窄屏和三种演示角色完成真实浏览器闭环，控制台无警告和错误。

2026-09-16 的轻量化调整只改变范围说明和默认界面层级，没有删除稳定服务端能力。数据来源/性能、模板权限、操作记录和简单状态流均改为默认折叠的可选增强。基础测试 56 项通过、11 项 MySQL 专项按未配置环境跳过；Vite 316 模块生产构建通过；本地浏览器确认设计页层级、折叠状态和响应式布局正常。

明确限制：

- 只承诺 `.xlsx` 基础导入与兼容提示，不承诺旧 `.xls` 或全部 Excel 高级特性；
- 不承诺多人实时协作、复杂 BPMN、企业组织权限或真实业务现场适配；
- Univer 工作区包体仍较大；
- 本地 JSON 记录与 SQLite 元数据不是统一事务；MySQL 适配器同样不与 SQLite 元数据组成跨库事务。
