# 通用类 Excel 应用构建平台（项目暂名）

## 我们在做什么

这是一个准备公开在 GitHub 的类 Excel 低代码应用构建项目。应用作者通过表格模板配置字段、公式、表间关系、权限和状态流并发布；应用使用者在发布后的表格中录入、粘贴、计算和查询；平台将记录结构化保存并保留版本和审计。

项目借鉴 MyExcel 的低学习门槛和活字格的应用搭建思路，使用 Univer 提供表格交互。目标是展示“表格模板如何成为数据库应用”，而不是针对某家公司交付 ERP、OA、排产或打印系统。

平台只有两个核心使用视角：

- 设计模式：搭建和维护模板、数据关系、规则、权限与状态流。
- 运行模式：使用已发布应用填写记录、查询、处理状态并查看结果。

Excel 式界面负责“怎么填、怎么算、怎么看”，结构化存储负责记录事实，表间关联负责让不同应用通过稳定记录关系取数、查询、汇总及受控回写。跨 Sheet 单元格公式不能代替这种业务关系。

## 代码结构

- `src/`：Vue 与 Univer 前端
- `server/`：Node.js API、原型元数据及业务数据访问
- `shared/`：前后端共用的数据模型和绑定契约
- `tests/`：自动化测试
- `scripts/`：开发、演示与维护脚本
- `docs/`：主设计、进度与补充要求
