# 通用类 Excel 应用构建平台（项目暂名）

> 文档更新：2026-09-23；产品基线 V1.9；进度台账版本以台账文件为准。

## 我们在做什么

这是一个公开在 GitHub 的类 Excel 应用构建项目。应用作者通过表格模板配置字段、公式和基础表间关系并发布；应用使用者在发布后的表格中录入、粘贴、计算和查询；平台将记录结构化保存。权限、状态流和审计属于可选增强，不是项目入门前提。

项目借鉴 MyExcel 的低学习门槛和活字格的应用搭建思路，使用 Univer 提供表格交互。目标是展示“表格模板如何成为数据库应用”，而不是针对某家公司交付 ERP、OA、排产或打印系统。

平台只有两个核心使用视角：

- 设计模式：搭建和维护模板、字段绑定、数据关系与发布版本。
- 运行模式：使用已发布应用填写、保存、查询和重新打开记录。

Excel 式界面负责“怎么填、怎么算、怎么看”，结构化存储负责记录事实，表间关联负责让不同应用通过稳定记录关系取数、查询、汇总及受控回写。跨 Sheet 单元格公式不能代替这种业务关系。

## 当前边界

阶段一已收敛为 8 项个人开源 MVP 能力，并在本地合成环境通过自动回归、构建和浏览器验收。旧 N-01—N-08 只是历史实施拆分，不再定义产品范围。已有实现、已知限制和唯一当前任务入口均以 [当前进度与交接](docs/PHASE1_PROGRESS.md) 为准。

核心成果覆盖原网格记录填写、主从绑定、基础关联取数与汇总、草稿和固定发布版本、XLSX 降级提示及合成示例。阶段 3 已增加版本化 HTTP/JSON API、OpenAPI、设计专用模板包以及可重复性能预算；服务端复算、回滚、权限、简单状态流、审计和 MySQL 仍作为可选增强保留。

公开仓库持续执行当前文件、配置和待同步提交的隐私/秘密扫描。演示只使用合成数据；跨平台快速开始见仓库根 [README](../README.md)，Windows 本机环境与旧脚本说明见 [本机开发环境](../environment/README.md)。

## 代码结构

- `src/`：Vue 与 Univer 前端
- `server/`：Node.js API、原型元数据及业务数据访问
- `shared/`：前后端共用的数据模型和绑定契约
- `tests/`：自动化测试
- `scripts/`：开发、演示与维护脚本
- `docs/`：主设计、进度与补充要求
